
# Взлом шифра Цезаря
>Юлий Цезарь был, якобы первым, кто придумал собственно шифр. Алфавит
размещается на круге по часовой стрелке. Для зашифровки буквы текста заменяются буквами, отстоящими по кругу на
заданное число букв дальше по часовой стрелке. Минимизация D(s) по всем s = 1,2,...,n дает ключ к расшифровке кода Цезаря.
>![alt](https://ru.wikipedia.org/wiki/%D0%93%D0%B0%D0%B9_%D0%AE%D0%BB%D0%B8%D0%B9_%D0%A6%D0%B5%D0%B7%D0%B0%D1%80%D1%8C)
## Цель проекта
Разработать программу, которая **автоматически расшифровывает** текст, зашифрованный *шифром Цезаря*, используя метод **частотного анализа** без знания ключа
### Задачи проекта
- [x] Изучить теорию шифра Цезаря
- [ ] Освоить метод частнотного анализа
- [ ] Реализовать подсчет частот букв
- [ ] Реализовать минимизацию функции различия `D(s)
- [ ] Протестировать программу
- [ ] Оформить документацию
